## Баги для исправления

1. **Множественные запросы профилей пользователей**  
   **Проблема**: При входе в чат с 10 пользователями выполняется 10 запросов профилей, возможно, запрашиваются данные всех пользователей, а не только текущих.  
   **Решение**: Оптимизировать запросы через batch-запросы или кэширование профилей. Ограничить выборку только участниками текущего чата.

2. **Публичные API точки отдают лишнюю информацию**  
   **Проблема**: API возвращает избыточные данные, включая Telegram-юзернеймы.  
   **Решение**: Провести аудит API, исключить конфиденциальные данные (например, юзернеймы) для неавторизованных пользователей.
